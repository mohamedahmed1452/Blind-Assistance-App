🧭 Blind Assistance App

Assistive Android Application for the Visually Impaired

A smart, accessible, and AI-powered Android application designed to support visually impaired users in their daily activities.
The app combines Image Caption Generation, Currency Classification, and Voice Navigation to deliver a seamless hands-free experience.

✨ Features
🖼️ Image Caption Generation

Uses advanced AI/ML image recognition models

Generates real-time descriptive captions

Helps users understand surrounding visual content

Provides spoken descriptions via Text-to-Speech

💵 Currency Classification

Detects and recognizes different currencies using the camera

Identifies denominations (e.g., 10, 20, 50, 100)

Ensures safe and independent financial handling

Works in real-time

🎙️ Voice Navigation

Full app control using voice commands

Provides continuous audio feedback

Designed for blind and low-vision users

Hands-free interaction with simple voice prompts

📥 Installation

Clone the repository:

git clone https://github.com/USERNAME/Blind-Assistance-App.git


Open the project in Android Studio.

Sync Gradle files.

Run the app on a real device with a camera (recommended).

▶️ Usage Guide
1. Image Captioning

Point the camera at any object

Tap the Capture button

The app speaks the caption automatically

2. Currency Classification

Point camera at a banknote

The app instantly announces the denomination

Works in low-light with optimized image preprocessing

3. Voice Navigation

Say “Start caption mode”, “Detect currency”, etc.

Navigate entirely without touch
